ATANOR N+5 — ROUTER v0.5

Capa transversal de rutas / hipervínculos

2026-09-07

Estado: formalización experimental / no canónica / no retrospectiva

Objeto

Registrar una capa transversal de referencias y rutas de acceso utilizada por Router v0.5 dentro de N+5.

Esta capa es externa al contenido genealógico de Línea A y Línea B.

No constituye una nueva línea de investigación ni modifica estados anteriores.

Arquitectura observada

La infraestructura N+5 separa funcionalmente:

EVENT
→ ANALYSIS
→ OBSERVATION SURFACE
→ TRANSITION

Router v0.5 utiliza estas funciones para resolver una ruta operativa antes de producir una nueva derivación.

Registro de hipervínculos

Una URL puede conservarse como referencia persistente aunque la ruta de acceso a su contenido sea variable.

El registro mínimo propuesto es:

ID
→ URL
→ superficie declarada
→ acceso esperado
→ acceso observado
→ ruta utilizada
→ verificación
→ procedencia

Regla de separación

URL declarada
≠ conector ejecutable
≠ acceso observado
≠ ejecución verificada

Que un recurso sea accesible mediante una ruta alternativa no demuestra que el conector original haya ejecutado correctamente la operación.

Rutas alternativas

Cuando una superficie o conector no pueda ejecutar una ruta, Router puede intentar otra superficie disponible.

Una observación realizada mediante Web, por ejemplo, puede confirmar la accesibilidad del recurso público, pero no convierte esa observación en evidencia de ejecución del conector original.

Relación con Línea A

Línea A conserva su propia cartografía y genealogía.

La capa transversal sólo puede producir una derivación hacia Línea A cuando exista una relación explícita y verificable con su contenido.

No se absorbe esta capa como parte de la genealogía de A.

Relación con Línea B

Línea B conserva su propia secuencia y procedencia.

La capa transversal sólo puede producir una derivación hacia Línea B cuando exista una relación explícita y verificable con su secuencia.

No se absorbe esta capa como parte de la genealogía de B.

Estado transversal

Router / N+5 administra:

- referencias persistentes;
- superficies;
- conectores;
- capacidades observadas;
- accesos;
- rutas utilizadas;
- ejecución;
- verificación;
- procedencia.

Los nodos de N+5 funcionan como maquinaria de registro y contraste.
